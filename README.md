# Isopxl downloads

Official Windows installer downloads for [Isopxl](https://isopxl.app).

## Download

Get the Windows x64 MSI installer from [Releases](https://github.com/shaynekasai/isopxl-downloads/releases).

No Windows release has been published here yet.

Published Windows release bundles include the installer, `SHA256SUMS.txt`, and `release.json`. The release process requires Azure code signing, timestamp verification, and Microsoft Defender checks before upload. Antivirus scans do not guarantee that software is free of malware or that every security product will accept it.

This repository contains download assets and release notes only. Isopxl application source is private. Public availability of an installer does not make the application open source; use remains subject to the application's license terms.
